# Lab 3 - TecniHogar

CC2008 - Programación Orientada a Objetos, UVG, Ciclo 2, 2026.

Aplicación de consola en Java para gestionar órdenes de servicio, cuadrillas y jornadas de TecniHogar usando herencia y polimorfismo.

## Requisitos

- Java 17 o superior (JDK)

## Compilar

    javac -encoding UTF-8 *.java

## Ejecutar

    java Main

Si en Windows se ven mal las tildes, ejecuta antes `chcp 65001` en la terminal.

## Uso

El menú permanece disponible hasta elegir la opción 0 (Salir). Los datos viven solo en memoria: al iniciar se cargan 8 órdenes pendientes (2 por categoría) y 3 cuadrillas, sin ingresos registrados.
